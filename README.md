# Montagem e desmontagem de computadores

Tutorial prático sobre o processo de desmontagem e montagem de um computador, realizado durante aulas práticas.

## Ferramentas necessárias

Para realizar a desmontagem e montagem do computador, foram utilizadas as seguintes ferramentas:

- Chave Phillips
- Pincel para limpeza
- Pinça

---

## Desmontando o PC Desktop

Antes de iniciar a desmontagem, é necessário desligar o computador, desconectar os cabos e organizar a bancada de trabalho.

### 1. Desligar o computador

O primeiro passo é desligar o computador e desconectar os cabos de alimentação e os demais periféricos.

![Desligando o computador](imagens/desmontagem01.jpg)

### 2. Remover a tampa do gabinete

Remova os parafusos responsáveis pela fixação da tampa do gabinete e retire-a cuidadosamente.

![Removendo a tampa do gabinete](imagens/desmontagem02.jpg)

### 3. Desconectar os cabos

Desconecte cuidadosamente os cabos que estão ligados aos componentes internos do computador.

![Desconectando os cabos](imagens/desmontagem03.jpg)

### 4. Remover os componentes

Após desconectar os cabos, retire os componentes internos seguindo a ordem realizada durante a aula prática.

![Removendo os componentes](imagens/desmontagem04.jpg)

### 5. Remover a memória RAM

Retire os módulos de memória RAM dos seus respectivos slots na placa-mãe.

![Removendo a memória RAM](imagens/desmontagem05.jpg)

### 6. Remover o processador e o cooler

Retire o sistema de refrigeração e, em seguida, o processador, seguindo os cuidados necessários.

![Removendo o processador](imagens/desmontagem06.jpg)

### 7. Remover a placa-mãe

Retire os parafusos de fixação e remova cuidadosamente a placa-mãe do gabinete.

![Removendo a placa-mãe](imagens/desmontagem07.jpg)

### 8. Realizar a limpeza

Com os componentes retirados, realize a limpeza do gabinete e dos componentes utilizando as ferramentas adequadas.

![Realizando a limpeza](imagens/desmontagem08.jpg)

---

## Montando o PC Desktop

Após finalizar a desmontagem, inicia-se o processo de montagem dos componentes no gabinete.

### 1. Preparar o gabinete

Verifique se o gabinete está preparado para receber novamente os componentes.

![Preparando o gabinete](imagens/montagem01.jpg)

### 2. Instalar a placa-mãe

Posicione a placa-mãe corretamente no gabinete e fixe-a utilizando os parafusos apropriados.

![Instalando a placa-mãe](imagens/montagem02.jpg)

### 3. Instalar o processador

Posicione o processador corretamente no soquete da placa-mãe.

![Instalando o processador](imagens/montagem03.jpg)

### 4. Instalar o cooler

Instale o cooler sobre o processador e certifique-se de que esteja devidamente fixado.

![Instalando o cooler](imagens/montagem04.jpg)

### 5. Instalar a memória RAM

Encaixe os módulos de memória RAM nos slots correspondentes da placa-mãe.

![Instalando a memória RAM](imagens/montagem05.jpg)

### 6. Instalar os demais componentes

Instale os demais componentes que foram retirados durante a desmontagem.

![Instalando os componentes](imagens/montagem06.jpg)

### 7. Instalar a fonte de alimentação

Posicione e fixe a fonte de alimentação no gabinete.

![Instalando a fonte](imagens/montagem07.jpg)

### 8. Conectar os cabos

Conecte novamente os cabos de alimentação e os demais cabos necessários para o funcionamento do computador.

![Conectando os cabos](imagens/montagem08.jpg)

### 9. Organizar os cabos

Organize os cabos dentro do gabinete para evitar que fiquem soltos ou atrapalhem os componentes.

![Organizando os cabos](imagens/montagem09.jpg)

### 10. Fechar o gabinete

Após verificar todas as conexões, coloque novamente a tampa do gabinete e fixe os parafusos.

![Fechando o gabinete](imagens/montagem10.jpg)

---

## Procedimentos após a montagem

Após finalizar a montagem do computador:

1. Verificar se todos os componentes estão corretamente instalados.
2. Conferir todas as conexões dos cabos.
3. Conectar os periféricos.
4. Conectar o cabo de alimentação.
5. Ligar o computador.
6. Verificar se o computador inicializa corretamente.
